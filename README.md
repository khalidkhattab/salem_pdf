# سجل الطلاب المفصولين

صفحة ويب لرفع كشف الطلاب المفصولين (PDF)، والبحث فيه بالاسم أو الصف/الفصل، وتصفيته حسب التاريخ أو الفترة، ثم تصديره PDF أو صورة أو مشاركته عبر واتساب أو طباعته.

- تتم قراءة الملفات داخل المتصفح فقط، ولا يُرفع أي ملف إلى أي خادم.
- البيانات تُحفظ في متصفح المستخدم نفسه (localStorage).
